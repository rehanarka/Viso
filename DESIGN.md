# Design

## Identity

Viso uses a dark, precision-oriented SaaS product language. The interface is built on deep charcoal surfaces, low-contrast borders, and a focused emerald accent.

## Colors

- Base: `#09090b`
- Surface: `#131315`
- Panel: `#18181b`
- Panel high: `#201f22`
- Border: `#27272a`
- Border strong: `#3f3f46`
- Text: `#fafafa`
- Muted text: `#a1a1aa`
- Accent: `#10b981`
- Accent bright: `#4edea3`
- Danger: `#ffb4ab`

## Typography

Use Plus Jakarta Sans for the interface, with JetBrains Mono for code and technical data moments. Headings are semibold to bold with tight but readable letter spacing. Body and label text stay compact and steady for product readability.

## Layout

The main surface uses a centered max width around `1280px`, 24px mobile gutters, and 32px desktop gutters. Sections are spacious, but cards and tables stay dense enough for scanning.

## Components

Cards use dark tonal surfaces with 1px borders and no decorative shadows. Buttons use an 8px radius. Primary buttons use emerald; secondary buttons use dark surfaces with zinc borders. Status chips use restrained accent tints.

## Motion

Motion is limited to hover/focus feedback, active press states, and subtle state changes. Reduced-motion users should receive instant transitions.
